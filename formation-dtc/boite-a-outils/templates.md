## 1. Brief créatif (module 08)

À envoyer à un créateur UGC, un monteur ou une agence. Une page.

```
BRIEF — [Marque] — [Nom du concept] — [Date]

1. OBJECTIF
   Pub pour de l'acquisition froide, Meta et TikTok, format 9:16, 30-45 s.

2. LE CLIENT
   Qui : [persona en une phrase, par situation — pas par âge]
   Sa situation au moment où il voit la pub : [ex. « son chat boit au robinet »]
   Ses mots : « … », « … », « … »   (extraits de la carte client)

3. L'ANGLE (un seul)
   [ex. Comportement / curiosité : « Pourquoi ton chat boit au robinet »]
   Niveau de conscience visé : [1 à 5]

4. L'ACCROCHE — 3 versions à tourner
   A. Visuel : …   Texte à l'écran : …   Phrase : …
   B. …
   C. …

5. LE DÉROULÉ
   0-3 s    Accroche
   3-10 s   Problème : …
   10-20 s  Solution, produit en action : …
   20-35 s  Preuves : …
   35-45 s  Offre et appel : « … »

6. À MONTRER ABSOLUMENT
   - Le produit en usage réel, en gros plan
   - [détail clé : ex. le démontage en 10 s]

7. À NE PAS DIRE / NE PAS FAIRE
   - Aucune promesse de santé ou de guérison
   - Pas de comparaison nommée avec un concurrent
   - Pas de « meilleur du marché » sans preuve
   - [spécifique à ta catégorie]

8. TON
   [3 adjectifs de la plateforme de marque] — parle comme à un ami, pas comme une pub.

9. EXEMPLES
   Liens vers 2-3 pubs de référence (les nôtres ou d'autres) + ce qu'on aime dedans.

10. LIVRABLES ET DROITS
    - 3 versions d'accroche + 1 corps, fichiers bruts + montage
    - Sous-titres incrustés
    - Droits : pub payante + organique, [pays], [durée], supports [Meta, TikTok…]
    - Mention « Publicité » si publication sur le compte du créateur
    - Date de livraison : …
```

## 3. Tableau de bord quotidien (module 01)

| Date | CA TTC | CA HT | Commandes | Panier moyen | Nouveaux clients | Dépense marketing | MER | nCAC | CM2 % | CM3 estimée | Conversion site | Jours de stock (héros) | Trésorerie hors TVA due |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | | |

**Formules :**
- `CA HT = CA TTC / 1,2` (ou la TVA moyenne pondérée de tes pays)
- `MER = CA TTC / Dépense marketing`
- `nCAC = Dépense d'acquisition / Nouveaux clients`
- `CM3 estimée = CA HT × CM2 % − Dépense marketing`
- `Jours de stock = Stock disponible / Ventes moyennes par jour sur 7 jours`

**Alertes (mise en forme conditionnelle) :** MER sous la cible 3 jours de suite ; nCAC
au-dessus du CPA cible 3 jours de suite ; CM3 négative ; jours de stock < délai
d'approvisionnement + 15 ; trésorerie < 6 semaines de dépenses.

## 4. Plan de stock (module 04)

Une ligne par produit, revue chaque lundi :

| Produit | Stock disponible | En transit (date d'arrivée) | Ventes / jour (7 j) | Croissance mensuelle prévue | Délai total (j) | Sécurité (j) | Point de commande | Stock + transit ≤ point ? | Quantité à commander | Coût rendu | Trésorerie nécessaire | Mode (bateau / avion) |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | |

**Formules :**
- `Point de commande = Ventes/jour × Délai total + Ventes/jour × Sécurité`
- `Quantité = Σ ventes prévues sur la période de couverture (avec croissance)`
- `Trésorerie = Quantité × Coût rendu` (acompte à la commande, solde avant expédition)
